# Command Block Scratch (Fabric, Minecraft 1.21.11)

Клиентский мод: открываете Scratch-подобный редактор, собираете скрипт из блоков — мод сам расставляет в мире цепочку командных блоков и записывает в них команды.

## Сборка

Нужны JDK 21 и интернет.

```
./gradlew build          # Windows: gradlew.bat build
```

Готовый мод: `build/libs/cbscratch-1.0.0.jar` (файл `-sources` не нужен). Положите его в `mods/` вместе с **Fabric API** (Fabric Loader 0.18+).

> Если Gradle ругается на версии (Loom / Fabric API / yarn) — сгенерируйте шаблон на https://fabricmc.net/develop для 1.21.11, возьмите оттуда `gradle.properties` и `build.gradle`, а папку `src/` оставьте из этого проекта.

## Как пользоваться

1. В творческом режиме с правами оператора (`/gamemode creative`, оп уровня 2+) встаньте и посмотрите на блок, рядом с которым хотите поставить цепочку.
2. Нажмите **K** (клавишу можно сменить в «Управление»).
3. Слева выберите вкладку и **перетащите** блоки в рабочую область:
   - начните с блока из «События» (он решает, как запускается скрипт);
   - блоки защёлкиваются друг под другом; C-блоки («если…», «от имени…», «повторить…») принимают блоки внутрь;
   - клик по полю — ввод текста (Enter — готово, Ctrl+Backspace — очистить поле); клик по полю со стрелкой ▾ — выбор из списка;
   - ПКМ по блоку — удалить; перетащить в палитру — тоже удалить; перетаскивание пустого места двигает рабочую область, колёсико — прокрутка.
4. Внизу видны итоговые команды (оранжевый — импульс, зелёный — цепочка, фиолетовый — повторяющийся).
5. **Поставить скрипт** / **Поставить все** — цепочка ставится от блока, на который вы смотрели, в выбранном направлении («Направление»; по умолчанию — куда смотрите). Несколько скриптов ставятся параллельными рядами через 1 блок.

«Копировать команды» кладёт команды в буфер обмена. Скрипты автоматически сохраняются в `config/cbscratch/workspace.json`.

## Как это работает

- Блоки ставятся командой `/setblock`, а команда, тип блока (импульс / цепочка / повторяющийся) и «всегда активен» задаются тем же пакетом, что отправляет GUI командного блока. Поэтому нужны права оператора и творческий режим, а мод на сервере **не нужен**.
- Первая команда получает режим события, остальные — «цепочка, всегда активен».
- «если / от имени / на позиции» превращаются в префикс `execute ... run` для каждой вложенной команды; «повторить N раз» разворачивается в N копий (максимум 64).
- Лимит: 400 команд на скрипт. Цепочка перезаписывает блоки на своём пути.

## Добавить свой блок

Одна строка в `model/BlockRegistry.java`:

```java
add(stack("say2", Category.CHAT, "крикнуть {msg|Эй!}", "say {msg}"));
```

В метке: `{ключ|текст}` — текстовое поле, `{ключ#5}` — число, `{ключ=a,b,c}` — список. В шаблоне: `{ключ}` — подстановка, `{ключ:j}` — подстановка с экранированием для JSON.

## Ограничения

- Блоков «ждать N тиков» нет: в командных блоках задержку без функций или таймеров не сделать.
- «Создать переменную» выдаёт ошибку, если такая уже есть, — ставьте её в отдельный скрипт «при запуске».
- Интерфейс лучше всего выглядит при масштабе GUI 2–3.
